## Dataset

**Lithium-Ion Battery Materials Dataset**

The dataset contains information about lithium-ion battery materials, including formation energy, band gap, density, crystal system, space group, volume, and other material properties.

---

## Project Objective

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on the Lithium-Ion Battery Materials Dataset using **R Programming**. The project includes data preprocessing, statistical analysis, data transformation, and visualization to gain meaningful insights into the dataset.
